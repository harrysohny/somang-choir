소망 찬양대 통합관리 V5

핵심 원칙
- 모든 데이터 입력/수정/삭제는 '통합 관리센터'에서 가능
- 데이터군마다 별도 관리권한 부여 가능
- 최고관리자는 모든 권한 보유

관리 데이터군
1. 대원/가입 승인
2. 공지
3. 연간 찬양곡·악보·파트별 연습영상·실제 찬양영상
4. 기도당번(목요일 날짜 / 주일 날짜 별도)
5. 일정·행사
6. 출석
7. 찬양대 소개
8. 섬기는 분들/임원
9. 갤러리
10. 자료실
11. 투표·설문
12. 봉사·할일
13. 회비·회계
14. 관리자 권한

권한은 대원별 체크박스로 선택할 수 있습니다.
예: 총무=공지+일정+기도+대원, 지휘자=찬양, 파트장=찬양/공지, 회계=회비·회계.

주의
- 이 버전도 브라우저 localStorage 기반 기능 시제품입니다.
- 여러 휴대폰에서 데이터를 공유하고 실제 로그인/승인을 사용하려면 다음 단계에서 Supabase 같은 온라인 DB 연결이 필요합니다.

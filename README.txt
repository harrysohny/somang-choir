소망 찬양대 앱 초안

포함 기능
- 대원 가입 신청
- 총무 승인 대기 상태 표시
- 홈 / 연간 찬양곡 / 공지 / 대원명단 / 더보기
- 정기연습 시간
- 기도당번
- 소망찬양대 소개
- 갤러리
- 권한별 관리 구조 표시

실제 운영용 다음 단계
1. 로그인 방식 결정 (휴대폰 번호 / 이메일 / 카카오 등)
2. 관리자 승인 DB 연결
3. 역할/권한(Role Based Access Control) 구현
4. 사진 업로드 저장소 연결
5. YouTube 링크 및 악보 PDF 등록 기능
6. 개인정보 열람 정책 확정

이 초안은 화면/흐름 검토용으로 localStorage를 사용합니다.


[최고관리자 설정]
- 기본 사용자 Harry Sohn을 최고관리자(Super Admin)로 설정
- permissions: all
- 가입 승인, 사용자 권한, 전체공지, 연간찬양곡, 기도당번, 영상/악보, 대원명단, 갤러리 관리 가능
- 현재 버전은 UI 시제품이므로 버튼은 관리화면 자리표시자입니다. 실제 DB 연결 후 기능이 활성화됩니다.

소망 찬양대 관리자 V3

주요 변경
- 모든 주요 콘텐츠 CRUD 지원
  · 공지 등록/수정/삭제
  · 연간 찬양곡 등록/수정/삭제
  · 기도당번 등록/수정/삭제
  · 소망 찬양대 소개 수정/초기화
  · 섬기는 분들 등록/수정/삭제
  · 갤러리 등록/수정/삭제
- 기도당번에서 목요일 날짜와 주일 날짜를 각각 명시
- 권한 세분화
  · 공지
  · 찬양곡/연습영상/실제영상
  · 기도당번
  · 찬양대 소개
  · 섬기는 분들
  · 갤러리
  · 대원명단
  · 다른 대원 권한 부여
- 최고관리자는 모든 권한 보유

주의
- 현재 버전은 브라우저 localStorage 기반 시제품입니다.
- 실제 여러 대원이 각자 휴대폰에서 공동으로 입력하려면 다음 단계에서 온라인 DB/Supabase 연결이 필요합니다.
